# Ask Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show Shania's full name above the question, and set the Yeayy page message to the exact new sentence.

**Architecture:** Static HTML and CSS only. The question card stays the dodge obstacle. Tests stay file-level `node --test` checks plus the existing placement tests.

**Tech Stack:** HTML, CSS, Node's built-in test runner. No build step and no `package.json`.

## Global Constraints

- Repository root is the GitHub Pages site. No build step.
- Question page, first row: `Shania Dea Menany Soputan` (slightly smaller, elegant, wraps on phones).
- Question page, second row: `Would you be my girlfriend?`
- Document title: `Would you be my girlfriend?`
- Celebration note, exact: `I'm so happyyy… I'm gonna die!` (U+0027, U+2026).
- `Yeayy!` heading stays.
- No still dodges 5 times then opens the sure page; sure Yes dodges; sure No returns home with the counter reset.
- Name must not cover the No button's lane on 360×800, 375×812, or short landscape.
- Do not add `package.json`.

### Task 1: Lock the new copy in the site test

**Files:**
- Modify: `test/site.test.mjs`
- Modify: `index.html`
- Modify: `yeayy.html`
- Modify: `css/styles.css`

**Interfaces:**
- Consumes: existing `node:test` file reads of `index.html`, `yeayy.html`, and `css/styles.css`
- Produces: an `ask-name` row whose text is the full name, an `h1` whose text is the question, and a celebration note with the exact sentence

- [ ] **Step 1: Write the failing test**

In `test/site.test.mjs`, replace the question and celebration assertions inside `the question, the sure page, and the celebration say the right things` with:

```javascript
  assert.match(index, /<title>Would you be my girlfriend\?<\/title>/);
  assert.match(index, /class="ask-name"[^>]*>\s*Shania Dea Menany Soputan\s*</);
  assert.match(index, /<h1>\s*Would you be my girlfriend\?\s*<\/h1>/);
  assert.doesNotMatch(index, /Shania, would you be my girlfriend\?/);
  assert.match(index, /href="yeayy\.html"/);
  assert.match(index, /data-dodge="count"/);
  assert.match(index, /data-limit="5"/);
  assert.match(index, /data-next="sure\.html"/);
  assert.match(index, /viewport-fit=cover/);
  assert.match(index, /manifest\.webmanifest/);
  assert.match(sure, /Are you sure\?/);
  assert.match(sure, /data-dodge="endless"/);
  assert.match(sure, /href="index\.html"/);
  assert.match(yeayy, /<h1>\s*Yeayy!\s*<\/h1>/);
  assert.match(yeayy, /I'm so happyyy… I'm gonna die!/);
  assert.doesNotMatch(yeayy, /I am so happy/);
```

In `styles respect safe areas, reduced motion, and the phone width`, add:
